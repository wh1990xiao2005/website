## V2.3.0（2026年6月30日）

## v1.0.0（2025年11月6日）

### 初始版本发布

#### 核心功能
- 基于 HTTP 服务器的局域网文件共享  
- 支持文件上传与下载  
- 二维码分享，便于快速访问  
- 可自定义共享目录  
- 网络连接状态监控  
- 屏幕常亮锁定选项  

#### 用户界面
- 简洁直观的主界面  
- 实时服务器状态显示  
- 网络信息卡片  
- 传输统计追踪  
- 提供多种配置选项的设置页面  

#### 国际化支持
- 双语界面（英文与中文）  
- 完整的本地化资源
