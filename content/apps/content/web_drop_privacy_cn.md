## 简介

「飞投」（以下简称"本应用"）是由萧文翰（以下简称"我们"）为您提供**局域网文件共享**功能的应用。飞投在您的设备上启动一个本地 HTTP 服务器，让同一 Wi-Fi 网络下的浏览器可直接访问、上传或下载您所选目录中的文件，所有数据传输均在您的设备与本地网络之间直接完成，不经过任何远端服务器。

我们非常重视您的个人信息和隐私保护，将按照法律要求和业界成熟的安全标准，为您的个人信息提供相应的安全保护措施。

## 1. 我们如何收集和使用您的个人信息

我们仅在有合法性基础的情形下才会处理与个人信息相关的信息。基于本应用**纯本地**的运行方式，我们不会向任何外部服务器收集、传输或出售您的个人信息。

### 1.1 我们在提供下列服务时会处理必要的信息

为实现核心功能，本应用会在**您的设备本地**处理以下信息，且仅在被您主动启用相应功能时才会处理：

1. **文件元数据（文件名、大小、修改时间）**：仅用于在网页端展示您所选共享目录下的文件列表，便于其他设备浏览与下载；
2. **本机网络信息（Wi-Fi 名称、本地 IPv4 地址）**：用于在网页端展示访问地址与生成二维码，不会上报；
3. **应用设置项**：包括共享目录路径、服务器端口、是否启用密码保护、只读模式、保持屏幕常亮等偏好，所有内容均通过 Android `SharedPreferences` 存储在您设备本地；
4. **会话令牌（Token）**：仅在您开启密码保护后，向已成功登录的访问者签发 12 小时内有效的 Bearer Token，存于内存，用于 API 鉴权，**不外发**；
5. **传输统计（上传/下载字节数、最近 1 秒速率）**：仅在内存中记录并显示在应用界面，用于您查看本次会话的传输状况，**不外发**。

您通过其他应用"分享到飞投"所发送的文件，会由本应用写入您选择的共享目录；该内容仅保留在您的设备本地，不会被传输给我们或第三方。

### 1.2 个性化推荐

## 2. 设备权限调用

本应用在运行过程中可能需要使用以下权限。我们会在使用前征求您的意见，任何未被您明确同意的权限，均不会被调用：

- **互联网访问**（`INTERNET`）：用于在您的设备上创建本地 HTTP 服务器，提供局域网文件共享；
- **网络状态访问**（`ACCESS_NETWORK_STATE`）：用于检测 Wi-Fi 连接状态，以便在 Wi-Fi 断开时自动停止服务；
- **更改网络状态**（`CHANGE_NETWORK_STATE` / `CHANGE_WIFI_STATE` / `ACCESS_WIFI_STATE`）：用于读取当前 Wi-Fi 名称、监听连接变化；
- **唤醒锁定**（`WAKE_LOCK`）：可选，仅在您开启"保持屏幕常亮"功能时使用，防止共享期间屏幕休眠；
- **前台服务**（`FOREGROUND_SERVICE`）：用于在共享期间维持后台运行，确保系统不会因资源紧张而中断本地服务；
- **媒体/文件访问**：在您选择的目录下读取与写入文件所必需。Android 11 及以上版本遵循分区存储（Scoped Storage）规范，低版本系统请求 `READ_EXTERNAL_STORAGE` / `WRITE_EXTERNAL_STORAGE`。

您可以随时进入系统"设置 → 应用 → 飞投 → 权限"管理上述权限。不同操作系统或应用版本所使用的权限或权限名称可能存在差异，具体以您实际使用的为准。

## 5. 第三方 SDK

为实现本应用的核心功能，我们集成了若干**开源** Flutter 插件与 Android 库。它们仅在您的设备本地工作，不存在向第三方服务器回传个人信息的行为，包括：

- **shelf / shelf_router**：提供本地 HTTP 服务；
- **network_info_plus** / **connectivity_plus**：读取设备网络状态；
- **shared_preferences** / **path_provider**：本地偏好与路径存储；
- **wakelock_plus**：屏幕常亮控制；
- **qr_flutter**：在本地生成访问地址二维码；
- **webview_flutter**：用于在 App 内展示隐私政策、版本说明等本地 HTML 资源；
- **open_file** / **package_info_plus** / **flutter_foreground_task**：用于打开文件、读取版本信息、维持前台服务。

本应用不存在以收集个人信息为目的的第三方 SDK、统计服务、推送服务或广告 SDK。

## 6. 如何保护您的个人信息

1. **本地网络限定**：HTTP 服务器绑定到您设备的局域网 IPv4 地址（`InternetAddress.anyIPv4`），仅在您所在的 Wi-Fi 网络内可访问，无法从公网访问；
2. **路径越权防护**：所有 HTTP 文件接口均通过 `FileUtils.isValidFilename` 校验，禁止 `..`、`/`、`\` 等路径穿越字符；
3. **可选访问控制**：您可以在"设置 → 密码保护"中开启 Bearer Token 鉴权，登录令牌有效期为 12 小时；
4. **可选只读模式**：您可以在"设置 → 只读模式"中禁止任何写入类操作（上传、重命名、删除、新建目录、移动），仅保留列表与下载；
5. **不持久化敏感数据**：本应用不记录文件内容、不持久化访问日志、不上报崩溃数据；
6. **最小化原则**：我们只会在达成上述目的所需的期限内，将配置保存在您的设备本地。

> **提示**：本应用默认不进行加密传输（局域网 HTTP）。请仅在受信任的 Wi-Fi 网络中启用共享，并尽量使用密码保护与只读模式。

## 7. 管理您的个人信息

由于本应用**不在云端存储任何个人信息**，您在大多数场景下无需主动管理。但我们仍提供以下通道保障您的权利：

### 7.1 信息访问

您可以在 App 内"设置"页面查看本机 IPv4 地址、共享目录路径、服务器端口、密码保护状态、只读模式状态、当前的上传/下载速率等运行信息。

### 7.2 信息更正

当您需要更新共享目录、端口、密码或相关偏好时，可在 App 内"设置"页面直接修改。所有配置均存储在您设备本地。

### 7.3 信息删除

您可以通过以下方式随时删除本应用存储的信息：

- 在"设置 → 空间清理"中清空所选目录下的文件；
- 在 App 内手动删除您不希望共享的文件；
- 通过卸载本应用清除所有本地数据。

### 7.4 撤销同意

若您不希望本应用继续使用某项权限，可在系统"设置 → 应用 → 飞投 → 权限"中随时撤销。撤销后，相关的核心功能可能无法正常运行。

### 7.5 注销服务

**不适用**。本应用不设账号体系，关闭共享或卸载应用即视为停止使用。

如您对上述数据主体权利有进一步要求或存在任何疑问、意见或建议，可通过本文"如何联系我们"章节中所述方式与我们取得联系。
