WebDrop（飞投） - 无线文件共享，从未如此简单

![App Logo](/images/webdrop_app_icon.png)

告别数据线、云盘上传和复杂的传输工具！飞投将你的 Android 设备变为安全、高性能的本地文件服务器。

![App ScreenShot](/images/webdrop_screenshot.png)

仅通过浏览器或任意 FTP 客户端即可实现跨设备即时文件共享。无论是向电脑传输照片、与同事分享项目文件，还是在手机与桌面端互传高清视频，飞投都能轻松搞定——无需联网、无需账号、无第三方中转。所有数据仅在局域网内流转，兼顾极速传输与绝对隐私。

➡️ 跨设备无缝共享：在任意现代浏览器（Windows/macOS/Linux/iPhone/iPad/Android）中打开共享文件夹，接收端无需安装任何应用；亦可使用 FileZilla、Cyberduck、系统自带文件管理器或 ftp 命令行等专业 FTP 客户端连接，扫码或输入局域网地址即可接入。

➡️ 双协议自由切换：内置 Web 与 FTP 双引擎，设置中一键切换，适配不同使用场景——网页直接拖拽上传或用 FTP 客户端走标准协议。

➡️ 安全至上：支持匿名传输与自定义凭据认证。

➡️ 局域网极速传输：内置专为 LAN 优化的传输引擎，设备直连速度远超云服务，轻松应对 4K 视频、RAW 照片、大型软件包等大文件传输；Web 模式下实时显示上传/下载速度与网络状态。

➡️ 无广告·无需注册·开箱即用：无任何广告、推广干扰，无需创建账号或登录，安装后启动服务即可使用；无文件大小限制、无付费会员，纯粹开放的本地共享体验。

➡️ 隐私至上设计：所有数据仅限 Wi-Fi 局域网内传输，无外部服务器、无数据采集、无遥测追踪，敏感文件安心共享，数字安全主义者的理想选择。

➡️ 多层级目录支持：支持通过 Web 端、FTP 客户端或应用内浏览器创建无限层级嵌套文件夹，告别扁平化文件列表，实现结构化文件管理与在线归档。

➡️ 只读模式：一键开启只读分享，Web 与 FTP 双端同步生效——Web 端禁止写入/删除/修改，FTP 端在协议层拦截 STOR/STOU/APPE/MKD/RMD/DELE/RNFR/RNTO 等所有写操作，状态横幅清晰标识当前模式，安全分发资料防误操作。

➡️ 快捷收件箱：其他应用可通过分享传输多个文件给本 App，从而轻松分享来自其它 App 的文件。

➡️ 智能文件管理：浏览、排序、筛选共享文件，支持图片预览、视频播放、音频试听；Web 端支持拖拽批量上传，检测并处理重名冲突。

➡️ Material Design 3 界面：简洁现代的响应式 UI，完美适配手机与平板，支持亮色/暗色主题切换。
